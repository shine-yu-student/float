## 2. 体验选手考场
相比于正式选手考场的豪华配置，体验选手考场的配置不可谓不寒碜。实际上，体验选手考场由两种不同的配置组成，较好的配置为 Intel(R) Core(TM) i3-8100 CPU，频率 3.60 GHz，内存 12 GB。而我十分不幸地被分配到了较差的配置，即 AMD Ryzen 7 5800H with Radeon Graphics，频率 3.20 GHz，内存 8 GB。以下是测评详情。
**以下代码均使用 C++14 标准，O2 优化，静态链接形式进行编译**。
### 1. 基于位运算的伪随机数生成（递归形式）
```c++
#include <cstdio>
using namespace std;
using ll = unsigned long long;
ll res, seed, N;
ll rnd()
{
	ll ret = seed;
	seed ^= (seed << 17);
	seed ^= (seed >> 5);
	seed ^= (seed >> 13);
	return ret;
}
void dfs(int x)
{
	if (x > N)
		return;
	dfs(x + 1);
	res ^= rnd();
}
int main()
{
	scanf("%llu%llu", &N, &seed);
	dfs(1);
	printf("%llu\n", res);
}
```
上述的代码使用了位运算生成伪随机数，并使用递归控制生成次数，使用 `res` 变量监控计算结果以免编译器直接删除函数。
令上述代码中 $N=10^7,seed=114514$ 时，该代码在上述配置较好的电脑上运行了 149ms，在配置较差的电脑上运行了 204ms。使用相同参数在我的笔记本上运行时，用时为 41ms。
### 2. 基于位运算的伪随机数生成（迭代形式）
当时，在机房中看见这个结果，有群友认为机器在递归上存在效率问题。于是，我将上述代码进行修改，得到了以下基于迭代的版本：
```c++
#include <cstdio>
using namespace std;
using ll = unsigned long long;
ll res, seed, N;
ll rnd()
{
	ll ret = seed;
	seed ^= (seed << 17);
	seed ^= (seed >> 5);
	seed ^= (seed >> 13);
	return ret;
}
int main()
{
	scanf("%llu%llu", &N, &seed);
	for (int i = 1; i < N; i++)
		res ^= rnd();
	printf("%llu\n", res);
}
```
该代码在上一代码的基础上省去了多层递归的操作，节省了压栈成本。
令上述代码中 $N=10^9,seed=114514$ 时，该代码在学校配置较差的电脑中运行了 1372ms。使用相同参数在我的电脑上运行时，用时为 1595ms。
### 3. 基于梅森旋转器的随机树生成/递归形式的树高计算
```c++
#include <cstdio>
#include <random>
#include <vector>
using namespace std;
const int N = 1e7 + 5;
int seed, n;
vector<int> e[N];
int dep[N];
void dfs(int x, int f)
{
	for (auto &i : e[x])
	{
		if (i == f)
			continue;
		dfs(i, x);
		dep[x] = max(dep[x], dep[i] + 1);
	}
}
int main()
{
	scanf("%d%d", &n, &seed);
	mt19937 mt(seed);
	for (int i = 2, f; i <= n; i++)
	{
		f = mt() % (i - 1) + 1;
		e[f].emplace_back(i);
		e[i].emplace_back(f);
	}
	dfs(1, 0);
	printf("%d\n", dep[1]);
}
```
上述代码使用了一种经典的随机树生成方法——对于节点 $i$，保证 $2\le i\le n$，在 $[1,i)$ 中随机选取一个节点作为其父节点。同时，上述代码的行为还包括了梅森旋转、`vector` 在大小超过其当前 `capacity` 时的自动扩张以及迭代器式遍历。
令上述代码中的 $n=10^7,seed=1145141$ 时，该代码在考场性能较差的电脑中运行了 4247ms。使用相同的参数在我的笔记本上运行时，用时为 2669ms。
### 4. 浮点数幂求和
```c++
#include <cstdio>
using namespace std;
const int N = 1e6 + 5, V = 1e8;
using ld = long double;
ld s = 0, t = 1, d;
int main()
{
	scanf("%Lf", &d);
	for (int i = 0; i < V; i++)
		s += (t *= d);
	printf("%.10Lf\n", s);
}
```
上述代码旨在测试 CPU 对浮点数的快速运算能力。

### 5. 整型位移/累加
```c++
#include <cstdio>
using namespace std;
using ull = unsigned long long;
ull n, i;
int main()
{
	scanf("%llu", &n);
	for (i = 1; i <= n; i++)
	{
		i <<= 1;
		i >>= 1;
	}
	printf("%llu\n", i);
}
```
上述代码旨在测试 CPU 对整数类型基本运算的处理效率。
令上述代码中 $n=10^{10}$ 时，该代码在考场中性能较差的电脑中运行了 4563ms，而使用相同参数在我的笔记本上运行时，用时为 2883ms。
### 6. 浮点矩阵乘法运算
```c++
#include <cstdio>
#include <random>
using namespace std;
const int N = 1e3 + 5;
using ld = long double;
ld f[N][N], g[N][N], h[N][N];
uniform_real_distribution<ld> r(0.0, 1.0);
int n, seed;
int main()
{
	scanf("%d%d", &n, &seed);
	mt19937 rnd(seed);
	for (int i = 0; i < n; i++)
	{
		for (int j = 0; j < n; j++)
		{
			f[i][j] = r(rnd);
			g[i][j] = r(rnd);
		}
	}
	for (int i = 0; i < n; i++)
		for (int j = 0; j < n; j++)
			for (int k = 0; k < n; k++)
				h[i][k] += f[i][j] * g[j][k];
	ld res = 0;
	for (int i = 0; i < n; i++)
		for (int j = 0; j < n; j++)
			res += h[i][j];
	printf("%Lf\n", res);
}
```
该代码计算两个值域为 $[0,1]$ 的 $n\times n$ 随机浮点数矩阵的乘积，旨在检验 CPU 对浮点随机分布的计算效率、浮点数的计算效率，内存的寻址效率等，是上述所有代码中对考场电脑进行的最综合的考验。
令上述代码中 $n=10^3,seed=1145141$ 时，该代码在考场性能较差的电脑中运行了 3079ms。使用相同参数在我的笔记本上运行时，用时为 2709ms。
### 3. 总结
对于正式选手的电脑，大可以相信它们具有与评测机相同的性能。
对于体验选手的电脑，此处以性能较差的电脑进行分析。通过上述结果可以看出，选手使用的电脑对整型基本运算具有**优秀**的效率，同时具有良好的数组寻址速度。这批电脑的劣势主要体现在**递归栈开销巨大**，这一点主要在上面的测试 1 和 3 中得到体现。也就是说，在考场上，若你的代码中使用了线段树/平衡树/分治等利用了递归函数的算法/数据结构，不妨认为该程序在评测机上的效率是你在你的电脑上看到的**两倍**。
