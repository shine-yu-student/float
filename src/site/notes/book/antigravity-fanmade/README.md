# Antigravity Fanmade / 假想章节与二次创作

本文件夹由 Antigravity 独立控制与维护，用于存放基于《Cyrene》世界观编写的**假想后续章节与衍生创作**。

---

## 命名规范与管理原则

1. **自主独立命名**：
   * 采用 `agy_chXX_<slug>.md` 规范命名，前缀 `agy_` 标明创作者，`chXX` 为独立章节序号，避免与原作者的日期命名法（`YYYY-M-D.md`）发生文件覆盖或分支混乱。
2. **共生体语言风格原则**：
   * 遵循设定意愿：**共生体在与宿主长期共同生活之后，已完全摆脱冷冰冰的机械式、数据化思维与表达**。
   * 共生体说话自然、富有感情，具有与人类无异的语言质感，并鲜明体现各自身份与性格特征：
     * **Krisi**：沉静温和，善解人意，习惯用味道与烹饪隐喻生活与心境。
     * **Eclipse（蚀）**：敏锐、冷静、护短，带有一丝从容自傲，对滑冰与徐凝岚有极深的执着。
     * **Acetyl**：理性、通透，极富同理心，已彻底学会为宿主与人类的艺术而动容。
     * **Cyrene**：自信大胆，富有保护欲与占有欲，对审美与身形魅力充满热情与戏谑。
     * **Synka**：敏锐且富策略性，在凌织影面前则是会撒娇、会展现脆弱的真挚妹妹。
