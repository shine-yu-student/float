卧室里的光线很暗。

厚重的遮光窗帘将窗外偶尔驶过的车灯与夜色彻底切断，仅有床头一盏暖黄色的球形小夜灯，在铺着深蓝色被褥的床沿晕开一圈极狭窄的昏沉光斑。

床边并肩坐着两个完全相同的身影。

高领无袖的深蓝色针织毛衣，露出一小截紧致而白皙的腹部；深蓝色的蕾丝短裙垂落至膝头；光裸的双足上，每一枚脚趾甲都被染成了静谧冷冽的深蓝；而摘去了所有发夹的黑蓝齐肩短发自然垂落，遮住了侧脸的线条。

最令人窒息的是她们的双眼。

那原本如冰湖般清透的深蓝色瞳孔中，所有的微光、反光与灵动的高光都被体内游走的黑色流体尽数吸收。没有情绪起伏带来的微颤，没有外界光源折射的斑点，只剩下两汪纯净无光、深不见底的幽暗深蓝。

寂静在卧室内蔓延开来。

在化为这一形态的最初数分钟内，徐凝岚听见了自己心跳的变化。那种急速涌动、充斥着愤懑与激昂的心率，以不可思议的速度沉降下去，平稳得像是一汪在极寒中彻底冻结的深潭。

脑海中那些关于过去的挣扎、对“正确四周跳”的厌烦、对猫头鹰与 SCA 的谋划，在这一刹那仿佛被一层厚重致密的丝绒彻底包裹、降噪。思维被精简到了前所未有的纯粹，如同剔除了所有杂质与毛刺的结晶。

然后，异变悄然滋生。

徐凝岚并没有开口，甚至没有转动脖颈。她的目光依旧平视着前方那面立在衣柜旁的穿衣镜，但她的眼角余光中，浮现出了身旁同样静止的 Eclipse。

在以往，她与 Eclipse 之间始终存在着清晰的界限——即便身体紧贴、即便记忆共享，徐凝岚依然是那个骄傲、别扭、偶尔会恼羞成怒的人类宿主；而 Eclipse 则是那个敏锐、克制、偶尔会带着一丝傲慢护短的共生体。

但此刻，随着眼眸中高光的熄灭，那道维系着“自我防御”与“独立叛逆”的精神壁垒，无声无息地崩解了。

徐凝岚忽然感受到了一种引力。

不是重力，也不是肌肉的牵拉，而是一种直接烙印在精神深处的、空前强大的牵引感。

她想把右手移向身侧。

仅仅是一个最细微的意念闪过，甚至尚未传导至运动神经，坐在她右侧的 Eclipse 便像是早有预兆一般，将自己冰凉柔软的左手掌心朝上，极其自然地摊开在深蓝色的被褥上。

徐凝岚的右手毫无阻碍地落了上去。

十指相扣。深蓝色的指甲在昏黄微光下轻轻摩挲，发出极轻细的摩挲声。

在指尖相触的刹那，徐凝岚的精神猛烈震颤了一下。

她没有在 Eclipse 的思维里读到任何质疑、任何试探，甚至没有一丝一毫属于独立个体的审视与防备。

那是一片辽阔、无垠、彻底敞开的深海。在 Eclipse 的意识深处，所有关于自我主张的棱角都已完全收敛，只剩下一个纯粹到近乎圣洁的意念——**完全地、无保留地顺从徐凝岚的一切。**

只要徐凝岚的心念微动，Eclipse 愿意化作任何形状、做出任何动作、放弃一切判断，成为她指尖下一具最完美的傀儡。

徐凝岚的心脏漏跳了一拍。

作为自幼独立生活、习惯了用浑身尖刺对抗孤独的少女，这种被另一方毫无保留交付全部主权的厚重感，让她感到一丝轻微的眩晕。

然而，更令她战栗的事情发生了。

当徐凝岚感知到 Eclipse 那份绝对服从的同一瞬间，一股同样强烈、同样无法抗拒的本能，自徐凝岚自己的心海深处轰然反扑。

——她也想要服从。

那并不是屈服，更不是被夺舍的傀儡化，而是一种源于“共生同调”极致之后的精神镜像反馈：

当 Eclipse 抹去了自身的一切抵触、将灵魂的提线完全交予徐凝岚的瞬间，徐凝岚的精神结构也被不可逆地同化了。

在徐凝岚的潜意识深处，原本属于人类骨子里的那份反叛、桀骜与自尊，在面对身边这个与自己分毫不差的人偶时，融化成了一种近乎病态的顺从本能。

Eclipse 微微收紧了指尖。

那甚至算不上一个命令，只是 Eclipse 在感受到徐凝岚体温后，潜意识里泛起的一丝希望更贴近一些的微弱波动。

徐凝岚的身体却在那一瞬间做出了最彻底的响应。

没有任何抗拒，没有任何犹豫。徐凝岚的身体自然而然地倾斜，肩膀靠向了 Eclipse 的肩头，下巴轻柔地搁在了 Eclipse 的颈窝处。

两人的呼吸同步在同一个频率，微凉的气流拂过彼此高领毛衣的边缘。

“岚……”

Eclipse 终于低低地呢喃出声。

那声音褪去了她平日里惯常的冷静与自矜，变得空灵、轻柔，甚至带着一种人偶特有的顺从韵律。

“我在。”徐凝岚回应道，声音轻得像是一片落羽。

她们依然没有转头对视，因为那双无光的深蓝眼眸里，早已不再需要视线的交汇来确认彼此。

Eclipse 感觉到了徐凝岚后颈处泛起的微凉。她抬起空着的右手，指尖顺着徐凝岚黑蓝色的发丝缓缓梳理而下，抚过那光洁而单薄的肩头。

在抚摸的过程中，Eclipse 的内心甚至没有产生“我要安慰她”这种自上而下的主观意愿。她只是感知到了徐凝岚意识深处对触碰的微弱接纳，于是她的肢体便顺应着那根无形的丝线，做出了最严丝合缝的服从。

而徐凝岚则完全放松了整具躯体的防线。

在过去十几年的人生里，她从未将自己的后背与脖颈如此毫无保留地暴露在任何人的指尖之下。即便在冰场上与教练、伙伴相处，她也是那个永远绷紧核心、警惕着下一次摔倒的战士。

但现在，只要 Eclipse 的手指稍有停顿，徐凝岚便会本能地微仰起头，将自己颈部的曲线更加顺从地迎合上去，任由那冰凉的指尖在自己微凸的锁骨与喉际流连。

没有命令。

没有言语。

甚至不需要思考“谁在操控、谁在顺从”。

在这个昏暗的卧室里，提线的概念被彻底模糊了——每一根自徐凝岚指尖延伸出的丝线，最终都缠绕回了她自己的脖颈；而自 Eclipse 灵魂深处递出的控制权，又在顷刻间化为了徐凝岚对她的完全交付。

她们既是至高无上的提线者，也是温驯至极的人偶。

“……真是奇怪的感觉呢。”

良久，徐凝岚的唇瓣微启，吐出一句轻微的呢喃。

“你不喜欢吗，岚？”Eclipse 的声音贴着她的耳廓响起，指尖顺着她的脊椎线条轻轻抚下，动作轻柔得如同在抚摩一件价值连城的瓷器。

徐凝岚阖上了那双无光的双眼。

在眼帘垂下的瞬间，整片世界重归于彻底的黑暗与纯粹。她感受着从身边那具躯体源源不断渗透过来的安宁与顺从，心中那一团盘踞了数日的狂躁怨念，竟在这种极致的互为傀儡中，被抚慰得没有留下一丝波纹。

“不……”徐凝岚的嘴角微微泛起一抹病态而安详的浅笑，“我很喜欢。”

得到这一声肯定的刹那，Eclipse 的身体微微放松，顺势将头也依偎在了徐凝岚的头顶。

穿衣镜里，两个完全一致的无光人偶在昏黄的灯晕下安静地叠合在一起，没有动作，没有言语，宛如一对在深蓝海底永久沉眠的古老雕塑。

丝线无形，却已深植骨髓。在这个深秋的深夜，一种超越了主仆、友谊与肉体共生的全新秩序，在这间闭锁的卧室内无声筑成。
