本文介绍一种科技。由于不久前才学到这个科技，目前并不知道该科技有什么广泛的应用。不过由于我为了解决这道题码了 4kb+ 的代码，所以纪念一下。
## 问题
给定长度为 $n$ 的正整数序列 $a$，要求求出无序不交区间对 $((l_1,r_1),(l_2,r_2))$ 的数量，满足 $\prod_{i=l_1}^{r_1} a_i \times\prod_{i=l_2}^{r_2} a_i$ 为完全 $k$ 次方数。
数据范围：$1\le n\le 500, 1\le k\le 10^9, 1\le a_i\le10^{36}$。
## 思路
令 $\mathbb{P}$ 为素数集。
对于任意不小于 $2$ 的整数 $x$，存在唯一分解方案 $x=p_1^{\alpha_1}\times p_2^{\alpha_2}\times\dots\times p_s^{\alpha_s}$，其中 $\forall 1\le i\le s,p_i\in\mathbb{P}$。
显然，$x$ 为完全 $k$ 次方数，当且仅当 $\forall 1\le i\le s,k\mid\alpha_i$。
所以，不难想到对所有 $a_i$ 暴力分解质因数，并对所有 $\alpha$ 进行模 $k$ 意义下的随机赋权哈希。然而，面对 $10^{36}$ 的数据范围，该算法显然不够优秀。
为解决这个问题，我们引入一种特殊的结构，**伪素数集**。
## 伪素数集
伪素数集为一个集合。为与素数集 $\mathbb{P}$ 区分，这里称其为 $\mathbb{P}^\prime$。**注意，本文中提到的伪素数集是相对于另一个正整数序列 $a$ 存在的，并不像 $\mathbb{P}$ 独立存在。所以，严格来说应该称其为 $\mathbb{P}^\prime_a$。**
该集合满足以下性质：
1. 对于 $a$ 中的任何元素，存在以 $\mathbb{P}^\prime_a$ 为底的唯一分解。形式化表达为 $\forall 1\le i\le n,a_i={{p^{\prime}}_1}^{\alpha^{\prime}_1}\times{{p^{\prime}}_2}^{\alpha^{\prime}_2}\times\dots\times{{p^{\prime}}_{s^\prime}}^{\alpha^{\prime}_{s^\prime}}$。其中，$\forall 1\le i\le s^\prime,p^\prime_i\in \mathbb{P}^\prime_a$。
2. $\mathbb{P}^\prime_a$ 中元素两两互质。形式化表达为 $\forall p,q\in\mathbb{P}^\prime_a\land p\neq q,\gcd(p,q)=1$。
通过使用如下算法，我们可以在 $O(n^2+n\log v)$ 的时间复杂度内求出任意正整数序列 $a$ 对应的 $\mathbb{P}^\prime_a$：
初始存在一个空集 $S$，创建另一个空集 $T$。依次取出 $a$ 中的元素 $x$，进行以下操作直到 $S$ 变为空集：
1. 取出 $S$ 中的任意元素 $y$。计算 $g=\gcd(x,y)$，并移除 $S$ 中的 $y$。
2. 若 $g=1$，则将 $y$ 加入 $T$，返回第 $1$ 步。
3. 否则，将 $g$ 加入 $S$ ，令 $x\leftarrow\frac{x}{g},y\leftarrow\frac{y}{g}$。若 $y\neq 1$，则将 $y$ 加入 $S$。
最后，若 $x\neq 1$，则将 $x$ 加入 $T$。
若遍历未完成，交换 $S$ 和 $T$，重复上述操作。
完成上述所有操作后，$T$ 即为 $\mathbb{P}^\prime_a$。
不难发现，通过上述方式对同一序列 $a$ 可以求出的 $\mathbb{P}^\prime_a$ 并不唯一。
## 解法
首先，通过上述方法求出 $\mathbb{P}^\prime_a$。初学者可能会认为可以直接使用 $\mathbb{P}^\prime_a$ 中的元素进行模 $k$ 意义下的哈希从而解决此题。然而，$\mathbb{P}^\prime_a$ 中的元素可能是完全 $c$ 次方数。若 $\gcd(k,c)\neq 1$，则可能出现 $a$ 中某个数为完全 $k$ 次方数，但哈希值并不为 $0$ 的情况。为了解决这个问题，我们需要对 $k$ 进行质因数分解。为什么呢？
首先，假设这个数是 $x$。$n$ 是使得 $x$ 是完全 $n$ 次方数的最大正整数。为了能在接下来的哈希处理中使用统一的模数 $k$，我们需要让 $x$ 变为 $\sqrt[\gcd(k,n)]{x}$。考虑这样做的原因。对于另一个数 $y$，若 $y=x^v$，则 $y$ 实际上是完全 $nv$ 次方数，若将这种情况延续到后面的哈希计算，则实现必然繁杂。那么为什么只需要开 $\gcd(k,n)$ 次根而不是 $n$ 次根呢？考虑一个与 $k$ 互质的数 $l$，实际上，$f(x)=lx\bmod k$ 是一个是一个 $[1,k-1]$ 到 $[1,k-1]$ 的单射，并不会对函数值转换后是否为 $0$ 产生影响。所以对 $k$ 进行质因数分解即可。
然而还存在一个问题。我们无法直接求出 $\gcd(k,n)$。原因也很简单，$x$ 太大了，我们不可能直接分解质因数。那么有没有一种快速的判断 $x$ 是否是完全 $n$ 次方数的方法呢？**有的兄弟，有的**。借助 `cmath` 库中的 `powl` 函数，我们可以快速计算一个 `long double` 类型浮点数的 $n$ 次根。显然，`long double` 可以存储 $10^{36}$ 级别的数字。但显然，由于 `long double` 的指数型存储方式，精度损失必然存在。此时，我们可以通过快速幂的结果对该函数得出的结果进行微调，若微调后刚好与 $x$ 吻合，则其为完全 $n$ 次方数，需要进行转换。对于 $k$ 的所有质因数依次进行上述操作即可完成转换。
按照上面的方法对 $\mathbb{P}^\prime_a$ 中的所有元素进行转换后，得到的新的 $\mathbb{P}^\prime_a$ 额外满足一个条件：
对于 $a$ 中所有元素 $a_i$，$a_i$ 为完全 $k$ 次方数，当且仅当其唯一分解 $a_i={{p^{\prime}}_1}^{\alpha^{\prime}_1}\times{{p^{\prime}}_2}^{\alpha^{\prime}_2}\times\dots\times{{p^{\prime}}_{s^\prime}}^{\alpha^{\prime}_{s^\prime}}$ 满足 $k\mid\gcd(\alpha^\prime)$。
完成这一步之后，接下来的步骤都非常简单。利用 $\mathbb{P}^\prime_a$ 对 $a$ 中每个元素进行分解伪质因数，枚举左右区间的分界点，将所有以该分界点为边界一侧的区间的哈希值插入一个 `map` 中，而另一侧的**反**哈希值用来对 `map` 进行查询来计算对答案的贡献。由于这不是这篇文章的重点，就不详细讲了。感兴趣的读者可以结合下面的代码自行理解，内有一些卡常/剪枝小技巧（`gp_hash_table` 加速查询/跳过 $k$ 的过大的质因数/时间戳+懒标记避免无用初始化/ $a$ 数组全部为 $1$ 的 $O(n)$ 计算）等等。
综上，本题在 $O(n^2+n\log v)$ 的时间复杂度内得到解决。
## 代码
```c++
// #define Redshift_Debug
#ifdef Redshift_Debug
#define debug(...) fprintf(stderr, __VA_ARGS__)
#include <chrono>
#else
#define debug(...)
#endif

#include <algorithm>
#include <cassert>
#include <cctype>
#include <cmath>
#include <cstdio>
#include <ext/pb_ds/assoc_container.hpp>
#include <random>
#include <set>
#include <utility>
#include <vector>

using namespace std;
using namespace __gnu_pbds;

const int N = 5e2 + 10, M = 2e5 + 10;

using ll = __int128;
using ull = unsigned long long;
using stt = pair<bool, ll>;
using pii = pair<int, int>;

set<ll> cur, buf;
int n, k, idx, kf[N], kc[N], kidx, bidx, cnt[N], vis[N], tst, tmpk;
ll a[N], g, tmp, buc[M];
ull res, hs[M], curv;
gp_hash_table<ull, int> mp;
vector<pii> dv[N];
random_device rd;
mt19937 mt(rd());

inline int adm(int x, int y)
{
	return (x + y >= k ? x + y - k : x + y);
}
template <typename _Tp> inline void read(_Tp &x)
{
	static char ch;
	while (ch = getchar(), !isdigit(ch))
		;
	x = (ch ^ 48);
	while (ch = getchar(), isdigit(ch))
		x = (x << 3) + (x << 1) + (ch ^ 48);
}
template <typename _Tp, typename... _Args> inline void read(_Tp &x, _Args &...args)
{
	read(x);
	read(args...);
}
template <typename _Tp> inline void print(_Tp x)
{
	if (x > 9)
		print(x / 10);
	putchar((x % 10) ^ 48);
}
template <typename _Tp, typename... _Args> inline void print(_Tp x, _Args... args)
{
	print(x);
	putchar(' ');
	print(args...);
}
template <typename _Tp> inline _Tp gcd(_Tp x, _Tp y)
{
	return y ? gcd(y, x % y) : x;
}
template <typename _Tp> inline _Tp fsp(_Tp x, int y)
{
	ll res = 1;
	while (y)
	{
		if (y & 1)
			res *= x;
		x *= x;
		y >>= 1;
	}
	return res;
}
stt check_pow(ll v, int k)
{
	ll rt = powl(v, 1.0 / k);
	while (fsp(rt, k) < v)
		rt++;
	while (fsp(rt, k) > v)
		rt--;
	return {fsp(rt, k) == v, rt};
}
void run()
{
	// Part 0: Input
	read(n, k);
	for (int i = 1; i <= n; i++)
		read(a[i]);

	// Part 1: Generate Pseudoprime Set
	if (a[1] != 1)
		cur.emplace(a[1]);
	for (int i = 2; i <= n; i++)
	{
		tmp = a[i];
		while (cur.size())
		{
			auto tv = *cur.begin();
			g = gcd(tv, tmp);
			cur.erase(cur.begin());
			if (g == 1)
			{
				buf.emplace(tv);
				continue;
			}
			cur.emplace(g);
			tv /= g, tmp /= g;
			if (tv != 1)
				cur.emplace(tv);
		}
		if (tmp != 1)
			buf.emplace(tmp);
		cur.swap(buf);
		buf.clear();
	}
	if (!cur.size())
	{
		for (int i = n; i; i--)
		{
			res += 1ull * (n - i + 1) * (i * (i - 1) / 2);
		}
		/*
		print(res);
		putchar('\n');
		*/
		return;
	}
	for (auto &i : cur)
		buc[++bidx] = i;

	// Part 2: Prime Factorization of k / Break down Pseudoprimes / Get Random Weight
	tmpk = k;
	for (int i = 2, tcnt; i * i <= tmpk; i++)
	{
		tcnt = 0;
		while (tmpk % i == 0)
			tcnt++, tmpk /= i;
		if (!tcnt)
			continue;
		kf[++kidx] = i;
		kc[kidx] = tcnt;
	}
	if (k != 1)
		kf[++kidx] = k, kc[kidx] = 1;
	for (int i = 1, tmpp; i <= bidx; i++)
	{
		tmpp = 128;
		for (int j = 1; j <= kidx and kf[j] <= tmpp; j++)
		{
			for (int tk = 1; tk <= kc[j]; tk++)
			{
				auto ret = check_pow(buc[i], kf[j]);
				if (!ret.first)
					break;
				buc[i] = ret.second;
				tmpp /= kf[j];
			}
		}
	}
	sort(buc + 1, buc + bidx + 1);
	bidx = unique(buc + 1, buc + bidx + 1) - buc - 1;
	for (int i = 1; i <= bidx; i++)
		hs[i] = mt() /*, print(buc[i]), putchar(" \n"[i == bidx])*/;

	// Part 3: Pseudoprime Factorization of A
	for (int i = 1; i <= n; i++)
	{
		for (int j = 1, tcnt; j <= bidx; j++)
		{
			if (a[i] == 1)
				break;
			tcnt = 0;
			while (a[i] % buc[j] == 0)
			{
				tcnt++;
				a[i] /= buc[j];
			}
			tcnt %= k;
			if (!tcnt)
				continue;
			dv[i].emplace_back(j, tcnt);
		}
	}

	// Part 4: Calculation
	for (int i = 2; i <= n; i++)
	{
		curv = 0;
		for (int j = i - 1; j; j--)
		{
			for (auto &tk : dv[j])
			{
				if (vis[tk.first] != tst)
				{
					vis[tk.first] = tst;
					cnt[tk.first] = 0;
				}
				curv -= cnt[tk.first] * hs[tk.first];
				cnt[tk.first] = adm(cnt[tk.first], tk.second);
				curv += cnt[tk.first] * hs[tk.first];
			}
			mp[curv]++;
			/*
			print(j, i - 1, curv);
			putchar('\n');
			*/
		}
		tst++;
		curv = 0;
		for (int j = i; j <= n; j++)
		{
			for (auto &tk : dv[j])
			{
				if (vis[tk.first] != tst)
				{
					vis[tk.first] = tst;
					cnt[tk.first] = 0;
				}
				curv -= cnt[tk.first] * hs[tk.first];
				cnt[tk.first] = adm(cnt[tk.first], k - tk.second);
				curv += cnt[tk.first] * hs[tk.first];
			}
			res += mp[curv];
		}
		tst++;
	}
	printf("%llu\n", res);
}
int main()
{
#ifdef Redshift_Debug
	auto st = chrono::high_resolution_clock::now();
#endif
	run();
#ifdef Redshift_Debug
	auto ed = chrono::high_resolution_clock::now();
	fprintf(stderr, "%.9lf\n", (ed - st).count() / 1e9);
#endif
}
```
