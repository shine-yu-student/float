## 声明
这一切的前提是，你上一次登录时选中了“下次登录时无需手机验证”的选项，而且电脑里面至少存在一个不会被恢复的卷。
## “D 盘”
首先需要意识到一件事情。这个 1TB 大的硬盘既然能够出现在这台电脑上作为数据盘，那么肯定有它的道理。就比如说，我们可以从中取出一些空间分一个新的盘。
Ubuntu 系统的软件区中有一个叫“磁盘”的软件。点开它，然后找到那个叫“1TB Hard Disk”的盘。就是它了。直接将原有的 NTFS 盘缩小 100G 开一个新的 ext4 盘，就可以给 linux 用了。
（其实 linux 可以用 NTFS，但是因为沟槽的大小写匹配规则导致一些东西不能用）
## .config 文件夹
打开一个 bash（或者 zsh 或者 fish 这些），cd 到 `~/.config` 目录。
在这个目录里面，你会看到一些应用的名字，而且它们大多都是文件夹。它们就是对应应用的配置文件。
**在处于登录状态时**进入 QQ 目录。
然后你会发现一些东西，比如说 `Trust Tokens`，`Session Storage` 这些。使用 `file` 指令发现 `Trust Tokens` 是一个 SQLite 数据库，而 `Session Storage` 里面包含一个叫做 `MANIFEST-000001` 的文件。它是一个 **PGP 密钥**。
综上，基本可以认为这个文件夹包含了许可登录所需要的一切条件。
## 操作
使用 `cp` 命令将 QQ 目录直接拷贝至不会恢复的卷。
下次重启电脑时，直接将 QQ 目录拷贝回 `.config` 目录，启动 QQ。此时你的头像和用户名会直接出现在屏幕上，点击登录会显示凭证过期。但是不要担心，切换到帐号密码登录模式重新输入账号密码就可以成功登录了。
